# Blog Application

## About the Project

The Blog Application is a responsive frontend web application that allows users to explore blog posts and create their own blogs. It provides a simple and user-friendly interface for managing blog content.

## Features

* Home page displaying the latest blogs
* Login page
* User registration page
* Dashboard to view blog posts
* Create new blog posts
* Responsive user interface
* Blog posts stored using browser Local Storage

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/poojasrichezhian/BlogApplication.git
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Explore the application and try creating blog posts.

## Current Limitations

* Login and registration are currently frontend demonstrations.
* Backend authentication and database integration are not implemented yet.
* Blog posts are stored locally in the browser.
